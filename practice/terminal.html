An easy guide to using Vim

What is Vim?

Vim is a text-only program that can be used to edit files in your computer terminal. It can be hard to learn at first, so here's a guide that should make it a little bit easier.

What Can You Do With Vim?

  • write code
  • edit files on your computer from the terminal
  • navigate quickly and efficiently through text

Navigating Vim

Opening Vim

  1. type Cmd + Space and then type "terminal" into the search bar
  2. cd into the correct directory in the terminal
  3. type vim <filename>

Modes in Vim

Normal Mode is the default mode in Vim. You can use this to quickly navigate through the file using the h/j/k/l keys (because Vim was created before the trackpad and mouse). You can also quickly switch to other modes in this mode. You can return to Normal Mode from other modes by typing the esc key.

Insert Mode is the mode used for editing the file. You can type normally, although you do have to move the cursor using the arrow keys as the mouse will not work. You can enter Insert Mode by typing "I" while in Normal Mode.

Command-Line Mode can be used to save, quit, or exit Vim, or change the settings of your Vim window. It can be accessed by typing ":" followed by your command.
